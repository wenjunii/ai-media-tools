Sealed editions remain unchanged. This log records corrections with their evidence.

## October 4, 2026 — LocalText2Voice release date

The LocalText2Voice guide's quality section incorrectly places the v2.2.0 release
on October 3 in Eastern time. GitHub records publication at
**2026-10-04 04:09:43 UTC**, which is **October 4, 2026, 12:09:43 AM EDT**
in America/New_York (UTC−04:00). Both dates are October 4.

The source release is [LocalText2Voice v2.2.0](https://github.com/estebanstifli/LocalText2Voice/releases/tag/v2.2.0);
the timestamp is available in the [GitHub release metadata](https://api.github.com/repos/estebanstifli/LocalText2Voice/releases/tags/v2.2.0).
This corrects only the timezone parenthesis in the
[sealed October 4 guide](../public/reports/2026-10-04/report.md).
