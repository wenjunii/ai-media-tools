## October 19, 2026 — OpenSuno-YuE2 software-license scope

The [October 11 screened entry](../public/reports/2026-10-11/report.md) identified
the repository's root MIT license. A current review of the
[third-party notices](https://github.com/victorcampeanu/OpenSuno-YuE2/blob/main/THIRD_PARTY_NOTICES.md)
found that bundled `transcriber/`, `mert/` and core model source retain
CC BY-NC 4.0 terms. This restriction applies to software, separately from the
non-commercial model weights. MIT covers original additions, not the complete
integrated song-generation application.

The historical entry remains preserved. Its current library assessment marks the
software-license check **failed**, keeps quality **unverified**, and explains why
the integrated workflow does not meet this project's open-source-only criterion.
No completed setup guide or recommendation is granted by this correction.

## October 4, 2026 — LocalText2Voice release date

The LocalText2Voice guide's quality section incorrectly places the v2.2.0 release
on October 3 in Eastern time. GitHub records publication at
**2026-10-04 04:09:43 UTC**, which is **October 4, 2026, 12:09:43 AM EDT**
in America/New_York (UTC−04:00). Both dates are October 4.

The source release is [LocalText2Voice v2.2.0](https://github.com/estebanstifli/LocalText2Voice/releases/tag/v2.2.0);
the timestamp is available in the [GitHub release metadata](https://api.github.com/repos/estebanstifli/LocalText2Voice/releases/tags/v2.2.0).
This corrects only the timezone parenthesis in the
[sealed October 4 guide](../public/reports/2026-10-04/report.md).
